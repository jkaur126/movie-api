# Movie API

## Description
A RESTful API for managing movie data with CRUD operations, filtering, sorting, pagination, authentication, authorization, Swagger documentation, and tests.

## Features
- Create, read, update, and delete movies
- Filter movies by genre, year, and rating
- Sort movies by title, release year, or rating
- Pagination support
- Firebase authentication
- Role-based authorization
- Swagger API documentation
- Jest test coverage

## Endpoints
- GET /movies
- GET /movies/:id
- POST /movies
- PUT /movies/:id
- DELETE /movies/:id
